# Qwen release cadence

Track Qwen model releases and updates since 2023. Compare release gaps and estimated release dates.

[Open the dashboard](https://nerdalytics.github.io/qwen-model-release-cadence-dashmodel/)

## Use the dashboard

- Choose All models, Core, or Coding and select a date range.
- Turn off Include updates for a narrower view of new model releases.
- Select a release to see its official announcement and source notes.
- Search the release log or export the results as CSV.
- Scroll or pinch to zoom. Use the controls below the graph to zoom or move through dates.

## Read the estimates

The dashboard shows two timing estimates. The average uses the release gaps in your selected range. The exponential moving average gives more weight to recent gaps.

These are estimates, not announced dates. With updates included, the next event could be a model update rather than a new generation.

## About the data

The history covers selected core and coding milestones, not every Qwen model. Sources are checked manually. It is not a live feed.

"Updated" is the date of the latest recorded event. "Checked" is the source-review date.

See the [source audit](SOURCE_AUDIT.md) for corrections and coverage limits.

Forecasts are separate for each model type. Select Max, Plus, Flash or a parameter size to see its history. All models shows separate forecasts for every type on the same graph. Past estimates stay marked as past; types with little data show a limited-history warning. The date-range filter changes the graph, not the forecast.

Compare ten forecasting methods, or use the checkboxes to show only the ones you want. Your algorithm selection is remembered in your browser. Open a method’s calculation details for its assumptions and historical errors. Probability windows are model-based estimates, not release announcements.
