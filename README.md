# Qwen release radar

Read Qwen's release history and compare forecasts for each model type.

[Open the radar](https://nerdalytics.github.io/qwen-model-release-cadence-dashmodel/)

The overview explains the recorded generation cycle. Model outlooks keep Max, Plus, Flash, coding models and individual sizes separate. Use Explore to compare ten forecast methods, change the date view, or zoom into the chart. Select a point for its evidence or calculation.

The radar follows your device's light or dark theme automatically. Forecast choices are remembered in your browser. Search the release log or export matching entries as CSV.

## Read the dates carefully

Forecasts are estimates, not announcements. Sparse histories can produce no forecast. Past estimates stay in the past. The date filter changes the chart, not the history used for forecasts.

The dataset is curated, not a live feed. Newer releases may be missing. The optional no-newer-release assumption changes only the probability methods.

Figures and numerical explanations update from the release data. See the [source audit](SOURCE_AUDIT.md) for coverage and corrections.
