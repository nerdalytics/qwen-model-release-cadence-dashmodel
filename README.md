# Cadence: Qwen release timing

Has Qwen's release pace slowed? Compare the gaps between Qwen releases with the dates that 10 statistical methods forecast.

[Open Cadence](https://nerdalytics.github.io/qwen-model-release-cadence-dashmodel/)

Start with the generation history and the method comparison. Separate model type cards cover API tiers such as Max, Plus and Flash, coding models and individual sizes. In Explore, choose a model type and pick from 10 forecasting methods. Select a point to see its source or calculation.

Search the release log or export matching entries as CSV. The page follows the light or dark theme of your device and remembers your method selection.

Updates to the dataset are manual, so the newest releases can be missing. The [source audit](SOURCE_AUDIT.md) lists coverage, terms and corrections.
