# Cadence: Qwen release timing

Has Qwen's release pace slowed? Compare the gaps between Qwen releases with the dates that 10 statistical methods forecast.

[Open Cadence](https://nerdalytics.github.io/qwen-model-release-cadence-dashmodel/)

Start with the generation history and the method comparison. Model type cards show API tiers (Max, Plus, Flash), coding models and individual sizes separately. In Explore, choose a model type and pick from 10 forecasting methods. Select a point for its source or calculation.

Search the release log or export matching entries as CSV. The page follows your device's light or dark theme and remembers your method selection.

The dataset is checked by hand, so the newest releases can be missing. See the [source audit](SOURCE_AUDIT.md) for coverage, terms and corrections.
