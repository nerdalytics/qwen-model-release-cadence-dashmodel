# Qwen release timing

Compare when Qwen's next models could arrive using their release history.

[Open the radar](https://nerdalytics.github.io/qwen-model-release-cadence-dashmodel/)

Start with the generation history and method comparison. Model charts show Max, Plus, Flash, coding models and individual sizes separately. In Explore, choose a model and select from ten forecasting methods. Open a point for its source or calculation.

Search the release log or export matching entries as CSV. The page follows your device's light or dark theme and remembers your method selection.

The dataset is checked manually and may lack newer releases. See the [source audit](SOURCE_AUDIT.md) for coverage and corrections.
