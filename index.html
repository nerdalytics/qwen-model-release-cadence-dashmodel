Methodology

How the calculations work

Which entries count

An entry is either a release or a model update. A release adds a new model. A model update changes an existing model, for example with a new checkpoint or a longer context. Generation counts the first public release of each numbered generation, including point releases such as Qwen3.5 to Qwen3.8, whether through the API or as open weights. Every other model type uses its own dates. Entries on the same day count once per model type.

Historical mean, recent methods and EMA

Historical mean averages every gap. EMA, the exponential moving average, starts with the first gap. Each later gap contributes 20%, and the running value keeps 80%. Recent mean and Recent median use the last 3 gaps. Weighted mean weights them 20%, 30% and 50%, oldest to newest. With fewer gaps, the available weights are rescaled to total 100%.

Trend and waiting-time methods

Holt trend tracks gap length and its change per gap. Damped Holt shrinks the projected change. Linear gap trend fits a straight line to gap length by gap number. Lognormal renewal fits a lognormal distribution to the gaps and uses its median. Bayesian partial pooling starts from the gaps of related model types and updates with the model type's own gaps. The API tiers Max, Plus, Flash and Turbo borrow from each other, Coder types borrow from other Coder types, and sizes borrow from other sizes.

Open a forecast in Explore to see its fitted values and how many gaps it needs.

Rounding, short gaps and filters

The page shows gaps in whole days. Each forecast date adds the rounded gap to the latest date. If every gap of a model type is shorter than 7 days, the page shows no forecast for it. Forecasts always use the full history of the model type. The Show history from filter only changes what the chart displays. Include model updates adds model updates to the Explore forecasts. Model type cards always include them.
