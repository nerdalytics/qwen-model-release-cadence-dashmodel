Methodology

How to read the release gaps and forecasts.

What the filters include

All models combines every event. Core includes core models and variants. Coding includes coding models. Turn off Include updates to exclude updates and variants.

Average release gap

The average uses gaps between consecutive events in your selected date range. Its forecast adds the average gap to the latest selected event date.

Exponential moving average

EMA starts with the first gap. Each new gap contributes 20% to the estimate; the previous estimate contributes 80%. Earlier history remains part of EMA when you narrow the date range. Its forecast also starts at the latest selected event.

Updates and timing

Events on the same day have a zero-day gap. With updates included, the next predicted event could be an update or variant rather than a new generation. Yellow shows EMA; cyan shows the average gap.

Forecasts are estimates, not announcements. They do not predict which model will release next. Past estimates stay in the past, and no future release dates are invented. The data is a manually checked snapshot, not a live feed.
