For planning

A forecast is not a delivery deadline.

If a project depends on the next model, compare the forecast assumptions before setting a deadline. Historical release gaps do not tell you what the supplier has committed to deliver.

Why the methods disagree

Generation history only

Each method gives different weight to the release history. That choice changes the forecast date.

What changes a forecast?

Adding a generation changes the latest interval and the date used to calculate the next forecast. Correcting an earlier date changes the historical gaps. The figures and explanations update from the release dataset.

The calculations below use the existing dataset. Sources are checked manually. Newer releases may be missing.

HOW TO READ THIS

The assumptions behind the dates

One history per model

A generation counts once, at its first public launch. That includes 3.5, 3.6, 3.7 and 3.8. Max, Plus, Flash, coding models and parameter sizes keep separate histories. Same-day entries count once per type.

Average is not a trend

The historical mean averages all recorded gaps. EMA gives each new interval 20% weight and the previous EMA 80%. It smooths changes. It does not project a shortening trend.

Recent mean, recent median and weighted mean focus on the last three intervals.

Other ways to estimate

Holt, damped Holt and linear regression model interval trends. Lognormal renewal models waiting times. Bayesian partial pooling combines a model's own gaps with a prior based on related model histories.

Select a forecast dot to see its calculation, history and limitations.

No guaranteed next release

Dates are estimates, not announcements. Past estimates stay in the past. Sparse histories may produce no date at all. The article and model charts use unconditioned estimates. Explore also offers an optional assumption of no newer release through today. Use it only after verifying the history.

Recorded evidence

Dates come from official announcements and dated repository news. The dataset is checked manually and may lack newer entries.
