Methodology

How the filters and estimates work.

Separate model histories

Max, Plus, Flash, parameter sizes and other types are calculated separately. A batch belongs to each type named in its source evidence. Coding sizes have separate histories from core sizes. Generation tracks recorded base-family launches. It is not the cadence of every Qwen model.

Average and EMA

Average is the mean of gaps between distinct dates for one type. EMA starts with the first gap, then gives each new gap 20% weight and the previous EMA 80%. Each estimate adds that interval to the latest entry for the same type.

Filters and updates

Date range changes the graph and log, not the forecast history. Core and Coding restrict the available types. Include updates adds recorded updates to each type’s history. Same-day entries count once per type. All types shows combined history without a model forecast.

Limited and past estimates

At least two dated entries are needed. Fewer than three intervals is marked limited history. A past estimate remains in the past. We do not restart the clock from today or invent missed releases.

These dates are estimates, not announcements. A past estimate does not prove a release was missed. The dataset may lack newer events. Sources are checked manually. This is not a live feed.
