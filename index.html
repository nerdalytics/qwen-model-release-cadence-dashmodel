Methodology

How the calculations work

Which events count

Generation counts the first public launch of each numbered family, including 3.5, 3.6, 3.7 and 3.8. Model types use their own launch dates. Entries on the same day count as one event per type.

Average, recent methods and EMA

Recent mean and recent median use the last three gaps. Weighted mean gives them 20%, 30% and 50% weight, oldest to newest. With fewer gaps, the available weights are rescaled to total 100%.

The historical mean and exponential moving average calculations are explained in the comparison above.

Trend and waiting-time methods

Holt tracks gap length and its change over time. Damped Holt reduces the projected change. Linear regression fits a straight line to the gaps. Lognormal renewal fits a waiting-time distribution. Bayesian partial pooling uses related types to inform the release rate.

Open a forecast for its fitted values and required history.

History and date filters

Each forecast uses the full history for its model type. The date filter changes the chart view. Include model updates also adds changes to existing models to the forecast history.
